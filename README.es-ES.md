

# 🔎 lookup.tools

La navaja suiza digital de herramientas de consulta. ¡Consulta información sobre dominios, IPs, direcciones de correo electrónico y más!

¡Pruébalo en acción en https://lookup.tools!

## Construido con

### Frontend

- [Cloudflare Workers](https://workers.cloudflare.com): Plataforma sin servidor para crear y desplegar aplicaciones
- [TanStack Start](https://tanstack.com/start): Marco de trabajo full-stack impulsado por TanStack Router
- [React](https://react.dev): Biblioteca frontend para interfaces de usuario web y nativas
- [Bun](https://bun.sh/): Kit de herramientas JavaScript todo en uno diseñado para la velocidad
- [Tailwind CSS](https://tailwindcss.com): Marco de trabajo CSS basado en utilidades
- [shadcn/ui](https://ui.shadcn.com): Biblioteca de componentes personalizable
- [Pigeon Maps](https://pigeon-maps.js.org): Mapas sin dependencias externas

### Backend

- [Robyn](https://robyn.tech): Marco de trabajo web para Python rápido construido en Rust
- [asyncwhois](https://github.com/pogzyb/asyncwhois): Utilidad de Python para consultas WHOIS y RDAP
- [holehe](https://github.com/megadose/holehe): Utilidad de Python para verificar cuentas registradas
